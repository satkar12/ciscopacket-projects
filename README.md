# Cisco Packet Tracer Projects

Welcome to my Cisco Packet Tracer networking portfolio!

This repository contains my networking labs and projects created using Cisco Packet Tracer.

## Projects

### 1. Two LANs Connected Through a Router

- **Devices:** Router, switches, and PCs
- **Concepts:** IP addressing, subnetting, and routing
- **Objective:** Connect two different LANs and enable communication between them.
- **Testing:** Verify connectivity using the `ping` command.

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- Networking fundamentals

## How to Use

1. Download the `.pkt` project file.
2. Open Cisco Packet Tracer.
3. Open the downloaded file.
4. Inspect the topology and test connectivity.
